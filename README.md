# Triple Whale — Finn agent test landing

Static POC landing page for customer testing. It deliberately uses distinct, prototype-only styling and includes an on-page disclosure that it is not the live Triple Whale website.

The page uses Finn's standard Docket widget loader (`ai-seller.js`) with agent ID `eb72a2a3-0253-412e-a4cd-f93da0749f3f`. The public GitHub Pages hostname must be allowlisted for the widget to load.
